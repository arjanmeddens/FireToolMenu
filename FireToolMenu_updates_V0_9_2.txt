FireToolMenu V0.9.1 updates

- Multi-selection feature for the available tools (after users select the "Phase" and "Step" inputs).
-- The selected tools are displayed in an interactive table using the `datatable` element from the `DT` R package (https://rstudio.github.io/DT/)
-- `inputdropdown3_selectOpt` is a reactive function that concatenates multiple selection of `input$dropdown3` as a single string for printing as output.
-- `get_SelectedToolTable()` is a reactive function that returns a `data.frame` used to render the data.table output
-- Relevant code can be found in lines: #L218, #L236, #L849, #L866 

- Download feature to get the available tools table as a csv, with a metadata file (.txt)
-- download feature is carried out via the `shiny::downloadHandler` (see download logic in the code under output$downloadTable)
-- the `get_SelectedChoicesMetadata()` is used for creating the metadata file. The function returns a character string used to write out the metadata as a txt file.
-- Relevant code can be found in lines: #L239, #L727
